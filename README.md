# SotACalc

**SotACalc** is an Android application designed for players of *Shroud of the Avatar*. It functions as an advanced skill and attunement optimization calculator, helping players figure out the most experience-efficient skill level distributions to hit their target magic attunement.

## Features

* **Magic School Selection:** Browse and choose skills tailored to specific magic schools.
* **Skill Customization & Locking:** Select your top ten optimization skills and lock specific skill values to lock down mandatory levels.
* **Smart Optimization Engine:** Automatically calculates optimal point distributions while respecting mathematical bounds and hard level limits (up to level 200).
* **Experience Breakdown:** Computes the exact total experience required for your optimized skill layout.
* **Modern Android UI:** Built with Jetpack Compose using a sleek dark theme tailored for mobile usage.

## Tech Stack

* **Frontend:** Kotlin, Jetpack Compose (Android)
* **Backend/Core Logic:** Python integrated via Chaquopy
